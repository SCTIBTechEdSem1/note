Principles of Internet Technologies and Web Applications

Unit 1: Web Fundamentals (5 Hours)
1.1 The Internet and the Web
i. Internet vs. World Wide Web.
ii. Brief history and evolution of the web.
iii. Web pages, websites, and web applications.
iv. Web 1.0, Web 2.0 and Web 3.0.

1.2 URLs, Domains, and DNS
i. Structure of a URL.
ii. Domain names and DNS lookup.
iii. Role of DNS in reaching websites.

1.3 Client–Server Architecture
i. Basic client–server model.
ii. 1-tier, 2-tier, and 3-tier architectures.
iii. Static vs. dynamic content.
iv. High-level view of modern web app architecture.

1.4 Core Internet and Web Protocols
i. TCP/IP and UDP.
ii. HTTP request–response cycle.
iii. Introduction to HTTPS and TLS/SSL.

1.5 APIs and JSON in Modern Web Applications
i. What an API is and why modern applications rely on them?
ii. REST-style thinking at a high level.
iii. JSON vs. HTML vs. XML: what each is used for.
iv. Simple example of a JSON response from a web service.

Unit 2: Hyper Text Markup Language (7 Hours)
2.1 Introduction to HTML and Document Structure
i. Introduction to HTML:
a. Overview of HTML's role in web development and the client-side structure of web pages.
b. The function of HTML in creating structured web content.
ii. Structure of an HTML document including meta tags, elements and attributes, writing Comments.

2.2 Basic HTML Elements and Text Formatting
i. Headings, Text Formatting: Paragraphs and Preformatted Text elements, Presentational Elements, Phrase Elements, Editing Elements, Grouping Elements.
• Build tables, lists, and embed external content such as maps or videos using iframes.
• Construct forms using common form controls and apply basic HTML5 validation attributes.
• Work with multimedia elements and apply semantic HTML5 sectioning tags to improve structure and accessibility.

2.3 Hyperlinks, Images, and URL Types
i. Hyperlinks:
a. The <a> element for linking.
b. Difference between absolute and relative URL with examples.
ii. Images:
a. Embedding images with the <img> tag.
b. Difference between ismap and usemap attributes with examples.

2.4 Tables, Lists, and Embedding External Content
i. Tables and Nested tables with attributes like colspan and rowspan.
ii. Lists:
a. Unordered lists, ordered lists, and definition lists
iii. Iframes for Embedding External Content:
a. Embedding external content using <iframe>.
b. Embedding Google Maps, YouTube videos, and other web pages.

2.5 Forms and Form Elements
i. Forms Overview:
a. Using <form> to create user input forms.
b. Form attributes: action, method and enctype.
ii. Form Elements: a. Input Elements: <input> types, <textarea>, <select>, <option>;, <button>, <label>. b. Fieldset and Legend: Grouping form elements with <fieldset> and adding a caption with <legend>.
iii. Validation:
a. HTML5 input validation: Required fields, pattern matching with pattern, and range control.


2.6 Multimedia and HTML5 Sectioning Elements
i. Working with Multimedia:
a. Embedding audio and video using <audio> and <video> tags.
b. Audio/video attributes: controls, autoplay, loop, and handling supported formats.
ii. HTML5 Sectioning Elements:
a. Using semantic HTML5 elements to structure
content: <article>, <section>, <nav>, <header>, <footer>, <aside>.

3.1 Introduction to CSS and Basic Syntax
i. Introduction to CSS:
a. Definition of CSS and its importance in web design for separating content from presentation.
ii. CSS Syntax:
a. Basic structure of CSS rules: selectors, properties, and values.
iii. Inserting CSS:
a. Inline CSS, Internal CSS and External CSS with examples.
iv. Writing Comments in CSS.

i. Basic Selectors, Attribute and Combinator Selectors, Pseudo-class and Pseudo-element Selectors.

a. Applying colors using keywords, hexadecimal codes and RGB.
ii. Backgrounds:
a. Applying background colors and images using the background property.
b. Controlling background repeat, position, and size.
iii. Text Styling:
a. Properties for controlling text appearance.

i. The CSS Box Model:
a. Understanding the box model and its components.

a. Intro to modern layout concepts: flexbox and grid.

3.5 Positioning, Float, and Alignment
i. Position Property:
a. Static, Relative, Absolute, Fixed and Sticky Positioning.

a. Using the float property to align elements to theleft or right of their container.
b. Using clear to control how floated elements
iii. Display:
a. Controlling element layout with the display property (block, inline, inline-block, none).

3.6 Responsive Web Design and Media Queries
i. Responsive Web Design Principles:
a. Building websites that adapt to different screen sizes and devices.
b. Using flexible grids, layouts, and images for responsiveness.
ii. Media Queries:
a. Syntax for media queries and how they enable responsive design (@media).
b. Targeting specific screen sizes (e.g., maxwidth, min-width).

d. Practical implementation of responsive design using media queries.

Unit 4: Client-Side Scripting with JavaScript (15 Hours)
4.1 Introduction to JavaScript and Adding JavaScript to a Page
i. Introduction to JavaScript:
a. Overview of JavaScript as a programming language for the web.
b. Role of JavaScript in adding interactivity to web pages.
c. Understanding JavaScript as a client-side language executed in the browser.
ii. Adding JavaScript to a Page:
a. Inline, Internal and External JavaScript
iii. Output in JavaScript:
a. document.write(), console.log() and alert().

4.2 Variables, Data Types, and Operators
i.Variables:
a. Declaring variables using var, let, and const.
b. Scoping rules for variables (block scope and function scope).
ii. Data Types:
a. Primitive and Non-primitive data types
b. The implications of type coercion and type conversion.
iii. Operators: a. unary, binary and ternary operators.

4.3 Control Statements and Functions
i. Control Statements:
a. Conditional Statements: if, else, else if, and switch for decision-making in code.
b. Loops: for, while, and do...while loops for repeated execution of code blocks.
ii. Functions:
a. Declaring functions using function declarations and expressions.
b. Function parameters and return values.
c. Named, anonymous and arrow functions.

4.4 Built-in Objects
i. Date Object:
Creating and manipulating dates, getting and setting date and time values.
ii. String Object: String manipulation methods.
iii. Array Object:
a. Creating and manipulating arrays in JavaScript (e.g., push, pop, shift, unshift).
b. Iterating over arrays using loops and the forEach() method.
c. Common array methods examples.

4.5 Document Object Model (DOM) Manipulation
i. The Document Object Model (DOM):
a. Introduction to the DOM and its hierarchical structure.
b. Selecting elements using getElementById(), getElementsByClassName(), getElementsByTagName() querySelector() and querySelectorAll().
ii. Modifying the DOM:
a. Changing element content using innerHTML, textContent and changing style.
b. Modifying attributes: setAttribute() and getAttribute().

4.6 Event and Error Handling, Form Validation, and Cookies
i. Event Handling:
a. Capturing user interactions with event handlers (e.g., onsubmit, onclick, ondblclick, onload, onmouseover, onmouseout, onmouseup, onmousedown).
b. Using addEventListener() for more flexible event handling.
ii. Error Handling (Try/Catch)
iii. Form Validation:
a. Client-Side Validation: Ensuring form fields are filled out correctly before submission.
b. Using Regular Expressions (Regex):
Introduction to regex for pattern matching. Validating input fields like text, emails, phone numbers, and passwords with regex patterns.
iv. Handling Cookies:
a. What are cookies, and why they are used in web development?
b. Creating, reading, and deleting cookies using JavaScript.

4.7 JSON and Data Handling
i. Introduction to JSON:
a. Overview of JSON and its role in web development.
b. JSON Structure: Understanding Key-Value Pairs and Supported Data Types.
ii. Working with JSON
a. Storing single and multiple data in JSON.
b. Accessing and updating JSON values (including nested objects and arrays).
c. Fetching and handling JSON from a mock API.
iii. Conversion Methods
a. Converting JavaScript objects to JSON strings and JSON strings to JavaScript objects.

4.8 Introduction to JavaScript Libraries andFrameworks
i. Why Libraries and Frameworks Emerged?
ii. Overview of Popular Technologies:
a. jQuery (its historical role in simplifying DOM manipulation and AJAX).
b. React (component-based thinking, state handling, unidirectional data flow, and serverside rendering).
c. Vue or Angular (examples of full-featured ecosystems for building structured, scalable applications).
